# Norbert Wiener Death Bot

An implementation of a "death bot" of Norbert Wiener using an LLM and vector search.

## Setup

- Login with `gcloud auth application-default login` before starting scripts that use google vertex ai.

## Data prep

- I used [docling](https://github.com/docling-project/docling) to parse the book pdfs
